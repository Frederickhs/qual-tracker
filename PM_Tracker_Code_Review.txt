# AGENTS.md

## Purpose

This file provides repository-wide instructions for coding agents such as OpenAI Codex, GitHub Copilot coding agent, Claude Code, and similar tools working on the PM Qualification Activity Tracker.

## Project Summary

The PM Qualification Activity Tracker processes unedited IBM Maximo qualification and task-status history exports. It generates one Excel workbook per venue:

- `Wolf Qualification Tracker.xlsx`
- `Darkmoor Qualification Tracker.xlsx`
- `Unchained Qualification Tracker.xlsx`

The normal user workflow must remain:

1. Download current Maximo reports as XLSX.
2. Place all qualification reports in `Input/Qualification`.
3. Place all rolling one-year task reports in `Input/Tasks`.
4. Double-click `Run Qualification Tracker.bat`.
5. Review the generated workbooks in `Output`.

The final user must not need to edit Python, use VS Code, use Power Query, or enter terminal commands for a normal monthly run.

### Matching rule

Match qualification records to completed task records using both:

```text
Qualification Labor/SSO = Task Change By/SSO
Qualification code = Task Qualification
```

Names are display fields only and must not be used as the primary key.

### Valid PM activity

A task counts when:

1. `Status` is exactly `COMP` after trimming and standardizing case.
2. SSO matches.
3. Qualification matches.
4. Completion date falls inside the applicable annual cycle.

Any individual qualifying task counts. A complete work order is not required.

### Annual cycles

Cycles remain permanently anchored to the original qualification Effective Date.

Example:

```text
Original qualification date: 2025-06-03
Cycle 1: 2025-06-03 through 2026-06-03
Cycle 2: 2026-06-03 through 2027-06-03
Cycle 3: 2027-06-03 through 2028-06-03
```

Generate Cycle 1 and every cycle that has started as of the processing date. Do not generate a future cycle before its start date.

Cycle boundaries are inclusive.

A PM counts only in the cycle containing its completion date. It must not carry into a later cycle or repair a missed earlier cycle.

If multiple valid tasks exist in one cycle, display the latest valid task.

### Status logic

```text
Valid PM exists                         -> Good / Completed
No PM and Days Remaining < 0            -> Requalification Needed
No PM and Days Remaining <= 30          -> Due Soon
No PM and Days Remaining > 30           -> Good
Task report unavailable for qualification -> Task Data Missing
```

Do not label missing task coverage as Good, Due Soon, or Requalification Needed.

### Inactive qualification records

Preserve inactive qualification records for audit visibility. Do not silently remove them. Their presence should be visible in Exceptions or equivalent review output.

## Maximo Input Rules

### Qualification reports

Qualification files do not reliably identify the qualification inside the workbook. The filename must contain exactly one approved qualification code, for example:

```text

UCMOD4 Qualification.xlsx
```

Expected worksheet:

```text

```

Expected fields include:

```text

```

Do not infer qualification from Work Location.

### Task reports

Task filenames do not matter. Identify task records using the internal `Qualification` column.

One task workbook may contain one or several qualifications. A qualification may also be split across multiple task files.

Expected fields include:

```text
Task Num
Status
Changed Date
Change By
Name
Qualification
```

The task description is normally stored in the first column.

Maximo XLSX reports can have incorrect worksheet dimensions. When using openpyxl in read-only mode, call:

```python
worksheet.reset_dimensions()
```

before iterating rows.

Maximo workbooks may show the harmless warning that a workbook contains no default style. Suppress only that specific warning. Do not suppress unrelated warnings globally.

## 4. Business Rules

### Qualification identity

Qualification reports do not contain a dependable qualification field. The qualification report filename must contain the exact qualification code, for example:

```text
DUMOD1 Qualification.xlsx
CUMOD2 Qualification.xlsx
UCMOD4 Qualification.xlsx
```

The program must not infer qualification from Work Location.

### Task identity

Task-report filenames do not matter. The program identifies task records using the internal `Qualification` column.

One task workbook can contain several qualifications. Qualifications can also be split across several task workbooks.

### Master matching key

```text
Qualification report Labor = Task report Change By
Qualification code = Qualification code
```

SSO and Qualification together identify a technician qualification. Names are display-only fields.

### Valid PM

A task is valid when:

- Status is `COMP`.
- SSO matches.
- Qualification matches.
- Changed Date falls inside the cycle.

Any single qualifying task meets the requirement.

### Annual cycles

Cycles are permanently anchored to the original Effective Date.

Example:

```text
Effective Date: 2025-06-03
Cycle 1: 2025-06-03 to 2026-06-03
Cycle 2: 2026-06-03 to 2027-06-03
Cycle 3: 2027-06-03 to 2028-06-03
```

The report creates all cycles that have started by the run date. It does not create future cycles early.

Dates on both boundaries count.

A PM belongs only to the cycle containing its completion date. PM activity never carries forward or backward between cycles.

If a cycle contains several valid tasks, the latest valid task is displayed.

### Status calculation

```text
Valid PM exists                   Good / Completed
No PM, due date passed            Requalification Needed
No PM, 30 or fewer days remain    Due Soon
No PM, more than 30 days remain   Good
Task source unavailable           Task Data Missing
```

The Task Data Missing state protects the report from falsely labeling records when a qualification task export has not arrived.

## 9. Excel Compatibility Issue and Fix

The initial `report_generator.py` used openpyxl Table objects. Desktop Excel opened the output with a repair warning and removed:

```text
AutoFilter from /xl/tables/table1.xml
Table from /xl/tables/table1.xml
AutoFilter from /xl/tables/table2.xml
Table from /xl/tables/table2.xml
```

The fix was:

- Remove `Table` and `TableStyleInfo` imports.
- Remove generated Table objects.
- Use normal worksheet ranges.
- Use `worksheet.auto_filter.ref = worksheet.dimensions`.

After regeneration, workbooks opened normally without repair warnings.

# PM Qualification Activity Tracker

Local Python application for processing IBM Maximo qualification and task-status history exports into annual PM compliance reports.

## What It Does

The tracker:

- Reads all current qualification reports.
- Reads every worksheet from all rolling one-year task reports.
- Keeps only completed tasks with `Status = COMP`.
- Matches technicians by SSO and qualification.
- Creates annual cycles tied permanently to the original qualification date.
- Assigns each PM task only to the cycle in which it was completed.
- Displays the latest valid task in each cycle.
- Calculates Good, Good / Completed, Due Soon, Requalification Needed, or Task Data Missing.
- Generates one Excel workbook per venue.

## Generated Reports

```text
Output/Wolf Qualification Tracker.xlsx
Output/Darkmoor Qualification Tracker.xlsx
Output/Unchained Qualification Tracker.xlsx
```

Each workbook contains:

- Dashboard
- PM Status
- Exceptions
- Run Summary

## Tracked Qualifications

### Darkmoor

- DUMOD1: Effects

### Wolf

- CUMOD1: RVs
- CUMOD2: Controls
- CUMOD3: Track

### Unchained

- UCMOD1: RVs
- UCMOD2: Controls
- UCMOD3: Track
- UCMOD4: Animation

The following Mod 0 safety qualifications are excluded:

```text
DUMOD0
CUMOD0
UCMOD0
```

## Business Rules

A PM task counts when:

- `Status = COMP`
- Task SSO matches qualification Labor/SSO
- Task qualification matches the technician qualification
- Completion date falls inside the applicable annual cycle

Cycles remain tied to the original qualification Effective Date.

Example:

```text
Qualification Date: 2025-06-03
Cycle 1: 2025-06-03 through 2026-06-03
Cycle 2: 2026-06-03 through 2027-06-03
Cycle 3: 2027-06-03 through 2028-06-03
```

A task counts only in its own cycle. It does not carry into another cycle.

Status rules:

```text
Valid PM exists                         Good / Completed
No PM and deadline passed               Requalification Needed
No PM and 30 or fewer days remain       Due Soon
No PM and more than 30 days remain      Good
Task report unavailable                 Task Data Missing
```

from datetime import datetime
from pathlib import Path
import shutil
import sys


PROJECT_ROOT = Path(__file__).resolve().parent.parent
OUTPUT_FOLDER = PROJECT_ROOT / "Output"
ARCHIVE_FOLDER = PROJECT_ROOT / "Archive"

OUTPUT_FILES = [
    "Wolf Qualification Tracker.xlsx",
    "Darkmoor Qualification Tracker.xlsx",
    "Unchained Qualification Tracker.xlsx",
    "Animation Qualification Tracker.xlsx",
]


def existing_output_files():
    return [
        OUTPUT_FOLDER / filename
        for filename in OUTPUT_FILES
        if (OUTPUT_FOLDER / filename).exists()
    ]


def create_unique_archive_folder():
    timestamp = datetime.now().strftime("%Y-%m-%d_%H%M%S")
    archive_run = ARCHIVE_FOLDER / timestamp / "Output"

    counter = 1
    while archive_run.exists():
        archive_run = ARCHIVE_FOLDER / f"{timestamp}_{counter}" / "Output"
        counter += 1

    return archive_run


def move_with_rollback(files, destination):
    moved = []

    try:
        destination.mkdir(parents=True, exist_ok=False)

        for source in files:
            target = destination / source.name
            shutil.move(str(source), str(target))
            moved.append((source, target))

    except Exception:
        for original, archived in reversed(moved):
            if archived.exists() and not original.exists():
                shutil.move(str(archived), str(original))

        try:
            if destination.exists() and not any(destination.iterdir()):
                destination.rmdir()
                parent = destination.parent
                if parent.exists() and not any(parent.iterdir()):
                    parent.rmdir()
        except OSError:
            pass

        raise


def main():
    print("Checking for previous output reports...")

    OUTPUT_FOLDER.mkdir(parents=True, exist_ok=True)
    ARCHIVE_FOLDER.mkdir(parents=True, exist_ok=True)

    files = existing_output_files()

    if not files:
        print("No previous tracker reports were found. Nothing to archive.")
        return 0

    archive_output = create_unique_archive_folder()

    try:
        move_with_rollback(files, archive_output)
    except PermissionError:
        print()
        print("ERROR: A previous output workbook is open or locked.")
        print(
            "Close all Wolf, Darkmoor, Unchained, and Animation "
            "output workbooks, then run again."
        )
        return 1
    except Exception as error:
        print()
        print(f"ERROR: Previous output reports could not be archived: {error}")
        print("Any files already moved were returned to Output when possible.")
        return 1

    print(f"Archived {len(files)} previous report(s) to:")
    print(f"  {archive_output}")
    return 0


if __name__ == "__main__":
    sys.exit(main())

from pathlib import Path
import sys
import time
import warnings

import pandas as pd
from openpyxl import load_workbook


PROJECT_ROOT = Path(__file__).resolve().parent.parent
TASK_FOLDER = PROJECT_ROOT / "Input" / "Tasks"
CONFIG_FILE = PROJECT_ROOT / "Config" / "qualification_mapping.csv"
LOG_FOLDER = PROJECT_ROOT / "Logs"
SUMMARY_FILE = LOG_FOLDER / "task_summary.csv"

SUPPORTED_EXTENSIONS = {".xlsx", ".xlsm"}
REQUIRED_TASK_COLUMNS = {
    "Task Num",
    "Status",
    "Changed Date",
    "Change By",
    "Name",
    "Qualification",
}

warnings.filterwarnings(
    "ignore",
    message="Workbook contains no default style*",
    category=UserWarning,
)


def normalize_text(value):
    if value is None:
        return ""
    return str(value).strip()


def get_task_files():
    return sorted(
        [
            file_path
            for file_path in TASK_FOLDER.iterdir()
            if file_path.is_file()
            and not file_path.name.startswith("~$")
            and file_path.suffix.lower() in SUPPORTED_EXTENSIONS
        ],
        key=lambda file_path: file_path.name.lower(),
    )


def load_tracked_qualifications():
    mapping = pd.read_csv(CONFIG_FILE, dtype=str).fillna("")
    mapping.columns = [normalize_text(column) for column in mapping.columns]

    required = {"Qualification", "Tracked"}
    missing = required.difference(mapping.columns)

    if missing:
        raise ValueError(
            "Configuration is missing columns: " + ", ".join(sorted(missing))
        )

    mapping["Qualification"] = (
        mapping["Qualification"].astype(str).str.strip().str.upper()
    )
    mapping["Tracked"] = mapping["Tracked"].astype(str).str.strip().str.lower()

    return set(
        mapping.loc[mapping["Tracked"] == "yes", "Qualification"]
    )


def find_header_row(worksheet, maximum_rows=15):
    for row_number, row in enumerate(
        worksheet.iter_rows(
            min_row=1,
            max_row=maximum_rows,
            values_only=True,
        ),
        start=1,
    ):
        headers = {
            normalize_text(value): index
            for index, value in enumerate(row)
            if normalize_text(value)
        }

        if REQUIRED_TASK_COLUMNS.issubset(headers):
            return row_number, headers

    return None, None


def read_completed_tasks(file_path):
    workbook = load_workbook(
        file_path,
        read_only=True,
        data_only=True,
    )

    completed_rows = []
    sheets_with_data = 0

    for worksheet in workbook.worksheets:
        worksheet.reset_dimensions()
        header_row_number, headers = find_header_row(worksheet)

        if headers is None:
            continue

        sheets_with_data += 1
        highest_index = max(headers.values())

        for row in worksheet.iter_rows(
            min_row=header_row_number + 1,
            values_only=True,
        ):
            if len(row) <= highest_index:
                continue

            status = normalize_text(row[headers["Status"]]).upper()

            if status != "COMP":
                continue

            qualification = normalize_text(
                row[headers["Qualification"]]
            ).upper()
            sso = normalize_text(row[headers["Change By"]])
            completion_date = row[headers["Changed Date"]]
            task_number = normalize_text(row[headers["Task Num"]])
            technician_name = normalize_text(row[headers["Name"]])

            first_value = normalize_text(row[0]) if row else ""
            task_description = first_value

            completed_rows.append(
                {
                    "SSO": sso,
                    "Technician Name": technician_name,
                    "Qualification": qualification,
                    "PM Completion Date": completion_date,
                    "Task Number": task_number,
                    "Task Description": task_description,
                    "Source File": file_path.name,
                    "Source Sheet": worksheet.title,
                }
            )

    workbook.close()
    return completed_rows, sheets_with_data


def main():
    started = time.perf_counter()

    print("=" * 70)
    print("PM Qualification Activity Tracker - Completed Task Reader")
    print("=" * 70)

    if not CONFIG_FILE.exists():
        print(f"ERROR: Configuration file not found: {CONFIG_FILE}")
        return 1

    task_files = get_task_files()
    print(f"Task reports found: {len(task_files)}")

    if not task_files:
        print("ERROR: No task reports were found.")
        return 1

    try:
        tracked_qualifications = load_tracked_qualifications()
    except Exception as error:
        print(f"ERROR: {error}")
        return 1

    all_completed_rows = []
    file_results = []

    for file_number, file_path in enumerate(task_files, start=1):
        print()
        print(f"[{file_number}/{len(task_files)}] Reading {file_path.name}...")
        file_started = time.perf_counter()

        try:
            rows, sheets_with_data = read_completed_tasks(file_path)
        except Exception as error:
            print(f"ERROR: {file_path.name}: {error}")
            return 1

        file_seconds = time.perf_counter() - file_started
        qualifications = sorted(
            {
                row["Qualification"]
                for row in rows
                if row["Qualification"]
            }
        )

        all_completed_rows.extend(rows)
        file_results.append(
            {
                "Source File": file_path.name,
                "Worksheets With Data": sheets_with_data,
                "COMP Rows": len(rows),
                "Qualifications": ", ".join(qualifications),
                "Processing Seconds": round(file_seconds, 1),
            }
        )

        print(f"  Worksheets processed: {sheets_with_data:,}")
        print(f"  COMP rows collected: {len(rows):,}")
        print(
            "  Qualifications: "
            + (", ".join(qualifications) if qualifications else "None")
        )
        print(f"  Processing time: {file_seconds:,.1f} seconds")

    completed = pd.DataFrame(all_completed_rows)

    if completed.empty:
        print()
        print("ERROR: No completed task rows were found.")
        return 1

    completed["SSO"] = completed["SSO"].astype(str).str.strip()
    completed["Qualification"] = (
        completed["Qualification"].astype(str).str.strip().str.upper()
    )
    completed["PM Completion Date"] = pd.to_datetime(
        completed["PM Completion Date"],
        format="mixed",
        errors="coerce",
    )

    exact_duplicate_mask = completed.duplicated(
        subset=[
            "SSO",
            "Qualification",
            "PM Completion Date",
            "Task Number",
            "Task Description",
        ],
        keep=False,
    )

    qualifications_found = set(
        completed.loc[
            completed["Qualification"] != "",
            "Qualification",
        ]
    )
    missing_qualifications = sorted(
        tracked_qualifications.difference(qualifications_found)
    )
    unknown_qualifications = sorted(
        qualifications_found.difference(tracked_qualifications)
    )

    summary = (
        completed.groupby("Qualification", dropna=False)
        .agg(
            COMP_Rows=("Task Number", "size"),
            Unique_Technicians=("SSO", "nunique"),
            Earliest_Completion=("PM Completion Date", "min"),
            Latest_Completion=("PM Completion Date", "max"),
            Invalid_Dates=(
                "PM Completion Date",
                lambda values: int(values.isna().sum()),
            ),
        )
        .reset_index()
        .sort_values("Qualification")
    )

    LOG_FOLDER.mkdir(parents=True, exist_ok=True)
    summary.to_csv(SUMMARY_FILE, index=False)

    total_seconds = time.perf_counter() - started

    print()
    print("Summary")
    print("-------")
    print(f"Task reports processed: {len(task_files)}")
    print(f"COMP rows combined: {len(completed):,}")
    print(f"Unique task technicians: {completed['SSO'].nunique():,}")
    print(
        "Exact duplicate task rows: "
        f"{int(exact_duplicate_mask.sum()):,}"
    )
    print(
        "Invalid completion dates: "
        f"{int(completed['PM Completion Date'].isna().sum()):,}"
    )
    print(f"Total processing time: {total_seconds:,.1f} seconds")
    print(f"Summary file created: {SUMMARY_FILE}")

    print()
    print("Qualifications found")
    print("--------------------")

    for qualification in sorted(qualifications_found):
        print(f"- {qualification}")

    if missing_qualifications:
        print()
        print("WARNING: Missing tracked task qualifications")
        print("--------------------------------------------")
        for qualification in missing_qualifications:
            print(f"- {qualification}")

    if unknown_qualifications:
        print()
        print("ERROR: Unknown task qualifications")
        print("----------------------------------")
        for qualification in unknown_qualifications:
            print(f"- {qualification}")
        return 1

    print()
    print("Completed-task reading finished successfully.")
    return 0


if __name__ == "__main__":
    sys.exit(main())

from pathlib import Path
from datetime import datetime

import pandas as pd


PROJECT_ROOT = Path(__file__).resolve().parent.parent
DATA_FOLDER = PROJECT_ROOT / "Data"
HISTORY_FILE = DATA_FOLDER / "cycle_history.csv"

KEY_COLUMNS = [
    "SSO",
    "Qualification",
    "Cycle Start Date",
    "Cycle Due Date",
]

HISTORY_COLUMNS = [
    "SSO",
    "Qualification",
    "Cycle Number",
    "Cycle Start Date",
    "Cycle Due Date",
    "PM Completion Date",
    "Task Number",
    "Task Description",
    "Task Source File",
    "First Recorded Date",
    "Last Confirmed Date",
]


def _normalize_dates(dataframe):
    result = dataframe.copy()

    for column in ["Cycle Start Date", "Cycle Due Date"]:
        result[column] = pd.to_datetime(
            result[column], format="mixed", errors="coerce"
        ).dt.normalize()

    result["PM Completion Date"] = pd.to_datetime(
        result["PM Completion Date"], format="mixed", errors="coerce"
    )

    for column in ["First Recorded Date", "Last Confirmed Date"]:
        if column in result.columns:
            result[column] = pd.to_datetime(
                result[column], format="mixed", errors="coerce"
            ).dt.normalize()

    result["SSO"] = result["SSO"].astype(str).str.strip()
    result["Qualification"] = (
        result["Qualification"].astype(str).str.strip().str.upper()
    )
    return result


def load_cycle_history():
    if not HISTORY_FILE.exists():
        return pd.DataFrame(columns=HISTORY_COLUMNS)

    history = pd.read_csv(HISTORY_FILE, dtype={"SSO": str})

    missing = set(HISTORY_COLUMNS).difference(history.columns)
    if missing:
        raise ValueError(
            "Cycle history is missing columns: "
            + ", ".join(sorted(missing))
        )

    history = _normalize_dates(history[HISTORY_COLUMNS])

    if history[KEY_COLUMNS].isna().any().any():
        raise ValueError(
            "Cycle history contains an invalid SSO, qualification, "
            "cycle start date, or cycle due date."
        )

    duplicate_keys = history.duplicated(subset=KEY_COLUMNS, keep=False)
    if duplicate_keys.any():
        raise ValueError(
            "Cycle history contains duplicate cycle keys. "
            "Review Data/cycle_history.csv before continuing."
        )

    return history


def _key_from_record(record):
    return (
        str(record["SSO"]).strip(),
        str(record["Qualification"]).strip().upper(),
        pd.Timestamp(record["Cycle Start Date"]).normalize(),
        pd.Timestamp(record["Cycle Due Date"]).normalize(),
    )


def apply_cycle_history(results):
    """
    Restore historical completed-cycle evidence and prepare the next history state.

    Only Good / Completed cycles are stored permanently. Temporary statuses are
    always recalculated from current qualification dates, task inputs, and today.
    """
    current = results.copy()
    current["SSO"] = current["SSO"].astype(str).str.strip()
    current["Qualification"] = (
        current["Qualification"].astype(str).str.strip().str.upper()
    )
    current["Cycle Start Date"] = pd.to_datetime(
        current["Cycle Start Date"], format="mixed", errors="coerce"
    ).dt.normalize()
    current["Cycle Due Date"] = pd.to_datetime(
        current["Cycle Due Date"], format="mixed", errors="coerce"
    ).dt.normalize()
    current["PM Completion Date"] = pd.to_datetime(
        current["PM Completion Date"], format="mixed", errors="coerce"
    )

    history = load_cycle_history()
    history_by_key = {
        _key_from_record(record): record
        for record in history.to_dict("records")
    }

    source_completed_keys = set()
    restored_count = 0
    newer_source_count = 0

    for index, row in current.iterrows():
        key = _key_from_record(row)
        current_completed = (
            row["Cycle Result"] == "Good / Completed"
            and pd.notna(row["PM Completion Date"])
        )

        if current_completed:
            source_completed_keys.add(key)

        historical = history_by_key.get(key)
        if historical is None:
            continue

        historical_date = historical["PM Completion Date"]
        current_date = row["PM Completion Date"]

        use_history = (
            not current_completed
            or pd.isna(current_date)
            or historical_date > current_date
        )

        if use_history:
            current.at[index, "PM Completion Date"] = historical_date
            current.at[index, "Task Number"] = historical["Task Number"]
            current.at[index, "Task Description"] = historical[
                "Task Description"
            ]
            current.at[index, "Task Source File"] = historical[
                "Task Source File"
            ]
            current.at[index, "Task Data Available"] = "Historical Evidence"
            current.at[index, "Cycle Result"] = "Good / Completed"
            restored_count += 1
        elif current_completed and current_date > historical_date:
            newer_source_count += 1

    run_date = pd.Timestamp.today().normalize()
    existing_first_recorded = {
        key: record["First Recorded Date"]
        for key, record in history_by_key.items()
    }
    existing_last_confirmed = {
        key: record["Last Confirmed Date"]
        for key, record in history_by_key.items()
    }

    completed = current[
        (current["Cycle Result"] == "Good / Completed")
        & current["PM Completion Date"].notna()
    ].copy()

    history_rows = []
    for record in completed.to_dict("records"):
        key = _key_from_record(record)
        first_recorded = existing_first_recorded.get(key, run_date)

        if key in source_completed_keys:
            last_confirmed = run_date
        else:
            last_confirmed = existing_last_confirmed.get(key, first_recorded)

        history_rows.append(
            {
                "SSO": str(record["SSO"]).strip(),
                "Qualification": str(record["Qualification"]).strip().upper(),
                "Cycle Number": int(record["Cycle Number"]),
                "Cycle Start Date": record["Cycle Start Date"],
                "Cycle Due Date": record["Cycle Due Date"],
                "PM Completion Date": record["PM Completion Date"],
                "Task Number": record.get("Task Number", ""),
                "Task Description": record.get("Task Description", ""),
                "Task Source File": record.get("Task Source File", ""),
                "First Recorded Date": first_recorded,
                "Last Confirmed Date": last_confirmed,
            }
        )

    updated_history = pd.DataFrame(history_rows, columns=HISTORY_COLUMNS)
    updated_history = updated_history.sort_values(
        ["Qualification", "SSO", "Cycle Start Date"], kind="stable"
    )

    stats = {
        "History records loaded": len(history),
        "Completed cycles in updated history": len(updated_history),
        "Cycles restored from history": restored_count,
        "Cycles updated by newer source task": newer_source_count,
    }

def normalize_text(value):

def load_mapping():

def qualification_from_filename(file_path, approved_codes):
    filename = file_path.stem.upper()
    matches = [code for code in approved_codes if code in filename]

    if len(matches) == 1:
        return matches[0]
    if not matches:
        raise ValueError("qualification code was not found in filename")
    raise ValueError("more than one qualification code was found in filename")


def read_qualifications(mapping):
    all_files = excel_files(QUALIFICATION_FOLDER)
    files = [
    file_path
    for file_path in all_files
    if "MOD0" not in file_path.stem.upper()
]
    approved_codes = set(mapping["Qualification"])
    reports = []
    detected_codes = []

    if not files:
        raise ValueError("No qualification reports were found")

    for file_path in files:
        qualification = qualification_from_filename(file_path, approved_codes)
        detected_codes.append(qualification)

        mapping_rows = mapping[mapping["Qualification"] == qualification]
        if len(mapping_rows) != 1:
            raise ValueError(
                f"{qualification} must have exactly one configuration row"
            )
        mapping_row = mapping_rows.iloc[0]

        workbook = pd.ExcelFile(file_path, engine="openpyxl")
        if "List of Labor" in workbook.sheet_names:
            sheet_name = "List of Labor"
        elif len(workbook.sheet_names) == 1:
            sheet_name = workbook.sheet_names[0]
        else:
            raise ValueError(
                f"{file_path.name}: worksheet 'List of Labor' was not found"
            )

        report = pd.read_excel(
            file_path,
            sheet_name=sheet_name,
            engine="openpyxl",
            dtype={"Labor": "string"},
        )
        report.columns = [normalize_text(column) for column in report.columns]

        required = {"Labor", "Name", "Effective Date", "Status"}
        missing = required.difference(report.columns)
        if missing:
            raise ValueError(
                f"{file_path.name}: missing columns: {', '.join(sorted(missing))}"
            )

        report = report.dropna(how="all").copy()
        report["SSO"] = report["Labor"].astype("string").str.strip()
        report["Technician Name"] = report["Name"].astype("string").str.strip()
        report["Qualification Date"] = pd.to_datetime(
            report["Effective Date"], format="mixed", errors="coerce"
        ).dt.normalize()
        report["Qualification Status"] = (
            report["Status"].astype("string").str.strip().str.upper()
        )
        report["Qualification"] = qualification
        report["Area"] = mapping_row["Area"]
        report["Venue"] = mapping_row["Venue"]
        report["Discipline"] = mapping_row["Discipline"]
        report["Qualification Source File"] = file_path.name

        reports.append(
            report[
                [
                    "Area",
                    "Venue",
                    "Discipline",
                    "Qualification",
                    "SSO",
                    "Technician Name",
                    "Qualification Date",
                    "Qualification Status",
                    "Qualification Source File",
                ]
            ]
        )

    duplicate_codes = sorted(
        {code for code in detected_codes if detected_codes.count(code) > 1}
    )
    if duplicate_codes:
        raise ValueError(
            "Duplicate qualification reports: " + ", ".join(duplicate_codes)
        )

    missing_codes = sorted(approved_codes.difference(detected_codes))
    if missing_codes:
        raise ValueError(
            "Missing qualification reports: " + ", ".join(missing_codes)
        )

    combined = pd.concat(reports, ignore_index=True)

    if combined["Qualification Date"].isna().any():
        count = int(combined["Qualification Date"].isna().sum())
        raise ValueError(f"Invalid qualification dates found: {count}")

    duplicate_mask = combined.duplicated(
        subset=["SSO", "Qualification"], keep=False
    )
    if duplicate_mask.any():
        count = int(duplicate_mask.sum())
        raise ValueError(f"Duplicate SSO and qualification rows found: {count}")

    return combined


def find_header_row(worksheet, maximum_rows=15):
    for row_number, row in enumerate(
        worksheet.iter_rows(
            min_row=1,
            max_row=maximum_rows,
            values_only=True,
        ),
        start=1,
    ):
        headers = {
            normalize_text(value): index
            for index, value in enumerate(row)
            if normalize_text(value)
        }
        if REQUIRED_TASK_COLUMNS.issubset(headers):
            return row_number, headers

    return None, None


def read_tasks():
    files = excel_files(TASK_FOLDER)
    rows = []

    if not files:
        raise ValueError("No task reports were found")

    for file_number, file_path in enumerate(files, start=1):
        started = time.perf_counter()
        print(f"[{file_number}/{len(files)}] Reading {file_path.name}...")

        workbook = load_workbook(file_path, read_only=True, data_only=True)
        file_count = 0

        for worksheet in workbook.worksheets:
            worksheet.reset_dimensions()
            header_row_number, headers = find_header_row(worksheet)
            if headers is None:
                continue

            highest_index = max(headers.values())

            for row in worksheet.iter_rows(
                min_row=header_row_number + 1,
                values_only=True,
            ):
                if len(row) <= highest_index:
                    continue

                status = normalize_text(row[headers["Status"]]).upper()
                if status != "COMP":
                    continue

                qualification = normalize_text(
                    row[headers["Qualification"]]
                ).upper()
                sso = normalize_text(row[headers["Change By"]])
                completion_date = row[headers["Changed Date"]]
                task_number = normalize_text(row[headers["Task Num"]])
                technician_name = normalize_text(row[headers["Name"]])
                task_description = normalize_text(row[0]) if row else ""

                rows.append(
                    {
                        "SSO": sso,
                        "Task Technician Name": technician_name,
                        "Qualification": qualification,
                        "PM Completion Date": completion_date,
                        "Task Number": task_number,
                        "Task Description": task_description,
                        "Task Source File": file_path.name,
                        "Task Source Sheet": worksheet.title,
                    }
                )
                file_count += 1

        workbook.close()
        seconds = time.perf_counter() - started
        print(f"  COMP rows collected: {file_count:,}")
        print(f"  Processing time: {seconds:,.1f} seconds")

    tasks = pd.DataFrame(rows)
    if tasks.empty:
        return tasks, set()

    tasks["SSO"] = tasks["SSO"].astype(str).str.strip()
    tasks["Qualification"] = (
        tasks["Qualification"].astype(str).str.strip().str.upper()
    )
    tasks["PM Completion Date"] = pd.to_datetime(
        tasks["PM Completion Date"], format="mixed", errors="coerce"
    )

    tasks = tasks.dropna(subset=["PM Completion Date"])
    tasks = tasks[tasks["SSO"] != ""].copy()
    tasks = tasks.drop_duplicates(
        subset=[
            "SSO",
            "Qualification",
            "PM Completion Date",
            "Task Number",
            "Task Description",
        ]
    )

    qualifications_found = set(tasks["Qualification"].dropna().unique())
    return tasks, qualifications_found


def add_years(date_value, years):
    return date_value + pd.DateOffset(years=int(years))


def build_cycles(qualifications):
    cycle_rows = []

    for record in qualifications.to_dict("records"):
        start = pd.Timestamp(record["Qualification Date"]).normalize()
        cycle_number = 1

        while start <= TODAY:
            due = add_years(start, 1)
            cycle_record = record.copy()
            cycle_record["Cycle Number"] = cycle_number
            cycle_record["Cycle Start Date"] = start
            cycle_record["Cycle Due Date"] = due
            cycle_rows.append(cycle_record)

            cycle_number += 1
            start = add_years(record["Qualification Date"], cycle_number - 1)

    return pd.DataFrame(cycle_rows)


def assign_tasks_to_cycles(cycles, tasks, qualifications_with_tasks):
    task_groups = {
        key: group.sort_values("PM Completion Date")
        for key, group in tasks.groupby(["SSO", "Qualification"])
    }

    output_rows = []

    for cycle in cycles.to_dict("records"):
        key = (str(cycle["SSO"]), cycle["Qualification"])
        task_data_available = cycle["Qualification"] in qualifications_with_tasks
        latest_task = None

        if task_data_available and key in task_groups:
            candidates = task_groups[key]
            valid = candidates[
                (candidates["PM Completion Date"].dt.normalize() >= cycle["Cycle Start Date"])
                & (candidates["PM Completion Date"].dt.normalize() <= cycle["Cycle Due Date"])
            ]
            if not valid.empty:
                latest_task = valid.iloc[-1]

        days_remaining = int((cycle["Cycle Due Date"] - TODAY).days)

        if not task_data_available:
            result = "Task Data Missing"
        elif latest_task is not None:
            result = "Good / Completed"
        elif days_remaining < 0:
            result = "Requalification Needed"
        elif days_remaining <= DUE_SOON_DAYS:
            result = "Due Soon"
        else:
            result = "Good"

        output = cycle.copy()
        output["Task Data Available"] = "Yes" if task_data_available else "No"
        output["PM Completion Date"] = (
            latest_task["PM Completion Date"] if latest_task is not None else pd.NaT
        )
        output["Task Description"] = (
            latest_task["Task Description"] if latest_task is not None else ""
        )
        output["Task Number"] = (
            latest_task["Task Number"] if latest_task is not None else ""
        )
        output["Task Source File"] = (
            latest_task["Task Source File"] if latest_task is not None else ""
        )
        output["Days Remaining"] = days_remaining
        output["Cycle Result"] = result
        output_rows.append(output)

    result = pd.DataFrame(output_rows)

    columns = [
        "Area",
        "Venue",
        "Discipline",
        "Qualification",
        "SSO",
        "Technician Name",
        "Qualification Date",
        "Qualification Status",
        "Cycle Number",
        "Cycle Start Date",
        "Cycle Due Date",
        "Task Data Available",
        "PM Completion Date",
        "Task Description",
        "Task Number",
        "Days Remaining",
        "Cycle Result",
        "Qualification Source File",
        "Task Source File",
    ]

    return result[columns].sort_values(
        ["Venue", "Qualification", "Technician Name", "Cycle Number"],
        kind="stable",
    )

    size_mb = size_bytes / (1024 * 1024)

def main():
    print("=" * 70)
    print("PM Qualification Activity Tracker - Qualification Reader")
    print("=" * 70)

    if not CONFIG_FILE.exists():
        print(f"ERROR: Configuration file not found: {CONFIG_FILE}")
        return 1

    files = get_qualification_files()
    print(f"Qualification reports found: {len(files)}")

    if not files:
        print("ERROR: No qualification reports were found.")
        return 1

    try:
        mapping = load_mapping()
    except Exception as error:
        print(f"ERROR: {error}")
        return 1

    tracked_mapping = mapping[mapping["Tracked"] == "yes"].copy()
    tracked_codes = set(tracked_mapping["Qualification"])

    reports = []
    errors = []
    detected_codes = []

    for file_path in files:
        qualification = qualification_from_filename(file_path)

        if qualification is None:
            errors.append(
                f"{file_path.name}: qualification code was not found in filename"
            )
            continue

        detected_codes.append(qualification)

        matching_rows = tracked_mapping[
            tracked_mapping["Qualification"] == qualification
        ]

        if matching_rows.empty:
            errors.append(
                f"{file_path.name}: {qualification} is not an approved tracked qualification"
            )
            continue

        if len(matching_rows) > 1:
            errors.append(
                f"{file_path.name}: duplicate configuration rows for {qualification}"
            )
            continue

        mapping_row = matching_rows.iloc[0]

        try:
            report = read_qualification_report(
                file_path,
                qualification,
                mapping_row,
            )
            reports.append(report)
            active_count = int((report["Status"] == "ACTIVE").sum())
            inactive_count = int((report["Status"] == "INACTIVE").sum())
            invalid_dates = int(report["Effective Date"].isna().sum())

            print()
            print(f"{file_path.name}")
            print(f"  Qualification: {qualification}")
            print(f"  Venue: {mapping_row['Venue']}")
            print(f"  Discipline: {mapping_row['Discipline']}")
            print(f"  Records: {len(report):,}")
            print(f"  Active: {active_count:,}")
            print(f"  Inactive: {inactive_count:,}")
            print(f"  Invalid qualification dates: {invalid_dates:,}")

        except Exception as error:
            errors.append(f"{file_path.name}: {error}")

    duplicate_input_codes = sorted(
        {
            code
            for code in detected_codes
            if detected_codes.count(code) > 1
        }
    )

    missing_tracked_codes = sorted(tracked_codes.difference(detected_codes))

    if duplicate_input_codes:
        errors.append(
            "Duplicate qualification report codes found: "
            + ", ".join(duplicate_input_codes)
        )

    if missing_tracked_codes:
        errors.append(
            "Missing tracked qualification reports: "
            + ", ".join(missing_tracked_codes)
        )

    print()
    print("Summary")
    print("-------")
    print(f"Reports successfully read: {len(reports)}")

    if reports:
        combined = pd.concat(reports, ignore_index=True)
        duplicate_keys = combined.duplicated(
            subset=["Labor", "Qualification"], keep=False
        )

        print(f"Qualification records combined: {len(combined):,}")
        print(f"Unique technicians: {combined['Labor'].nunique(dropna=True):,}")
        print(
            "Duplicate SSO and qualification rows: "
            f"{int(duplicate_keys.sum()):,}"
        )

        summary = (
            combined.groupby(
                ["Area", "Venue", "Qualification", "Discipline"],
                dropna=False,
            )
            .agg(
                Records=("Labor", "size"),
                Unique_Technicians=("Labor", "nunique"),
                Active=("Status", lambda values: int((values == "ACTIVE").sum())),
                Inactive=("Status", lambda values: int((values == "INACTIVE").sum())),
                Invalid_Dates=("Effective Date", lambda values: int(values.isna().sum())),
            )
            .reset_index()
        )

        LOG_FOLDER.mkdir(parents=True, exist_ok=True)
        summary.to_csv(SUMMARY_FILE, index=False)
        print(f"Summary file created: {SUMMARY_FILE}")

    if errors:
        print()
        print("ERRORS")
        print("------")
        for error in errors:
            print(f"- {error}")
        return 1

    print()
    print("Qualification report reading completed successfully.")
    return 0

    sys.exit(main())

def normalize_sso(value):
    if pd.isna(value):
        return ""

    text = str(value).strip()
    if text.endswith(".0"):
        text = text[:-2]
    return text


def normalized_name_tokens(value):
    if pd.isna(value):
        return []

    text = str(value).upper().replace("(UDX)", " ")
    return sorted(re.findall(r"[A-Z0-9]+", text))


def read_animation_roster(qualifications):
    if not ANIMATION_ROSTER_FILE.exists():
        raise ValueError(
            "Animation roster was not found. Expected: "
            f"{ANIMATION_ROSTER_FILE}"
        )

    roster = pd.read_excel(
        ANIMATION_ROSTER_FILE,
        engine="openpyxl",
        dtype={"ID": "string", "Name": "string"},
    )
    roster.columns = [str(column).strip() for column in roster.columns]

    required_columns = {"Name", "ID"}
    missing_columns = required_columns.difference(roster.columns)
    if missing_columns:
        raise ValueError(
            "Animation roster is missing columns: "
            + ", ".join(sorted(missing_columns))
        )

    roster = roster.dropna(how="all").copy()
    roster["Roster Name"] = roster["Name"].fillna("").astype(str).str.strip()
    roster["SSO"] = roster["ID"].apply(normalize_sso)

    official = qualifications[
        qualifications["Qualification"] == "UCMOD4"
    ].copy()
    official_by_sso = {
        str(row["SSO"]): row
        for row in official.to_dict("records")
    }

    exceptions = []

    for row_number, row in roster.iterrows():
        if not row["SSO"]:
            exceptions.append(
                {
                    "Exception Type": "Blank or invalid SSO",
                    "Roster Name": row["Roster Name"],
                    "SSO": "",
                    "Official Maximo Name": "",
                    "Details": f"Roster row {row_number + 2} has no usable ID.",
                }
            )

    nonblank = roster[roster["SSO"] != ""].copy()
    duplicate_mask = nonblank.duplicated(subset=["SSO"], keep=False)

    for _, row in nonblank[duplicate_mask].iterrows():
        exceptions.append(
            {
                "Exception Type": "Duplicate roster SSO",
                "Roster Name": row["Roster Name"],
                "SSO": row["SSO"],
                "Official Maximo Name": "",
                "Details": "The SSO appears more than once in Animation Roster.xlsx.",
            }
        )

    unique_roster = nonblank.drop_duplicates(subset=["SSO"], keep="first")
    matched_ssos = set()

    for _, row in unique_roster.iterrows():
        sso = row["SSO"]
        official_row = official_by_sso.get(sso)

        if official_row is None:
            exceptions.append(
                {
                    "Exception Type": "SSO not found in UCMOD4",
                    "Roster Name": row["Roster Name"],
                    "SSO": sso,
                    "Official Maximo Name": "",
                    "Details": (
                        "The roster SSO was not found in the official "
                        "UCMOD4 qualification report."
                    ),
                }
            )
            continue

        matched_ssos.add(sso)
        official_name = str(official_row["Technician Name"])

        if normalized_name_tokens(row["Roster Name"]) != normalized_name_tokens(
            official_name
        ):
            exceptions.append(
                {
                    "Exception Type": "Roster name differs from Maximo",
                    "Roster Name": row["Roster Name"],
                    "SSO": sso,
                    "Official Maximo Name": official_name,
                    "Details": (
                        "The official Maximo name is used in the generated report."
                    ),
                }
            )

    exception_frame = pd.DataFrame(exceptions, columns=ROSTER_EXCEPTION_COLUMNS)
    return matched_ssos, exception_frame, len(unique_roster)


def write_dataframe(worksheet, dataframe):
    worksheet.append(list(dataframe.columns))

    for row in dataframe.itertuples(index=False, name=None):
        worksheet.append(list(row))


def format_table_sheet(worksheet, status_column="P"):
    worksheet.freeze_panes = "A2"

    header_fill = PatternFill("solid", fgColor="548235")
    header_font = Font(color="FFFFFF", bold=True)

    for cell in worksheet[1]:
        cell.fill = header_fill
        cell.font = header_font
        cell.alignment = Alignment(horizontal="center", vertical="center")

    widths = {
        "A": 15,
        "B": 15,
        "C": 15,
        "D": 14,
        "E": 31,
        "F": 18,
        "G": 20,
        "H": 14,
        "I": 18,
        "J": 18,
        "K": 19,
        "L": 21,
        "M": 44,
        "N": 16,
        "O": 16,
        "P": 26,
    }

    for column, width in widths.items():
        worksheet.column_dimensions[column].width = width

    for row in worksheet.iter_rows(min_row=2):
        if len(row) >= 16:
            row[3].number_format = "@"
            row[5].number_format = "m/d/yyyy"
            row[8].number_format = "m/d/yyyy"
            row[9].number_format = "m/d/yyyy"
            row[11].number_format = "m/d/yyyy h:mm AM/PM"
            row[12].alignment = Alignment(wrap_text=True, vertical="top")

    if worksheet.max_row >= 2:
        worksheet.auto_filter.ref = worksheet.dimensions

        status_range = f"{status_column}2:{status_column}{worksheet.max_row}"
        for status, (fill_color, font_color) in STATUS_STYLES.items():
            worksheet.conditional_formatting.add(
                status_range,
                FormulaRule(
                    formula=[f'${status_column}2="{status}"'],
                    fill=PatternFill("solid", fgColor=fill_color),
                    font=Font(color=font_color, bold=True),
                ),
            )

from pathlib import Path

SUPPORTED_EXTENSIONS = {".xlsx", ".xlsm"}

# Maximo-generated workbooks may not contain Excel's normal default style.
# This warning does not affect the report data.
warnings.filterwarnings(
    "ignore",
    message="Workbook contains no default style*",
    category=UserWarning,
)


def get_task_files():
    return sorted(
        [
            file_path
            for file_path in TASK_FOLDER.iterdir()
            if file_path.is_file()
            and not file_path.name.startswith("~$")
            and file_path.suffix.lower() in SUPPORTED_EXTENSIONS
        ],
        key=lambda file_path: file_path.name.lower(),
    )


def normalize_header(value):
    if value is None:
        return ""
    return str(value).strip()


def find_header_row(worksheet, maximum_rows=15):
    """Find the Maximo header row instead of assuming it is row 1."""
    for row_number, row in enumerate(
        worksheet.iter_rows(min_row=1, max_row=maximum_rows, values_only=True),
        start=1,
    ):
        headers = {
            normalize_header(value): index
            for index, value in enumerate(row)
            if normalize_header(value)
        }

        if "Qualification" in headers and "Status" in headers:
            return row_number, headers

    return None, None


def inspect_workbook(file_path):
    print()
    print("=" * 70)
    print(f"File: {file_path.name}")
    print("=" * 70)

    workbook = load_workbook(file_path, read_only=True, data_only=True)

    qualifications = set()
    total_sheets = len(workbook.sheetnames)
    sheets_with_task_data = 0
    task_rows = 0
    completed_rows = 0
    first_header_row = None

    for worksheet in workbook.worksheets:
        worksheet.reset_dimensions()
        header_row_number, headers = find_header_row(worksheet)

        if headers is None:
            continue

        sheets_with_task_data += 1

        if first_header_row is None:
            first_header_row = header_row_number

        qualification_index = headers["Qualification"]
        status_index = headers["Status"]
        highest_needed_index = max(qualification_index, status_index)

        for row in worksheet.iter_rows(
            min_row=header_row_number + 1,
            values_only=True,
        ):
            if len(row) <= highest_needed_index:
                continue

            qualification = row[qualification_index]

            if qualification is None:
                continue

            qualification = str(qualification).strip().upper()

            if not qualification:
                continue

            qualifications.add(qualification)
            task_rows += 1

            status = row[status_index]

            if status is not None and str(status).strip().upper() == "COMP":
                completed_rows += 1

    workbook.close()

    print(f"Worksheets found: {total_sheets}")
    print(f"Worksheets with task data: {sheets_with_task_data}")
    print(f"First detected header row: {first_header_row or 'Not found'}")
    print(f"Task rows found: {task_rows:,}")
    print(f"COMP rows found: {completed_rows:,}")
    print("Qualifications found:")

    if qualifications:
        for qualification in sorted(qualifications):
            print(f"  - {qualification}")
    else:
        print("  None")
